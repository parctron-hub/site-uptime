# site-uptime — табло доступности сайтов

Заведено 05.11.2026 по просьбе пользователя: мерить доступность
centrfenix.ru, fenix-siz.ru, ncarus.ru, csb-fenix.ru каждые 30 минут и
дать ссылку, которой можно поделиться. 06.11.2026 добавлены
check.centrfenix.ru и check.fenix-siz.ru (другой сервер, 45.130.41.14).

## Как устроено
- `check.py` — проверка (stdlib, без зависимостей). «Работает» = код 200 и
  тело ≥ 5 КБ (заглушка Beget 274 байта и страница DDoS-Guard — «недоступен»),
  «медленно» = дольше 5 с, один повтор через 15 с перед вердиктом «недоступен».
  Пишет `docs/data/history.jsonl` (90 дней) и `docs/data/status.json`.
- `.github/workflows/check.yml` — GitHub Actions. **Не cron «*/30»**: GitHub
  на бесплатном репо запускает расписание с задержкой в часы (05.11.2026 —
  3 запуска за сутки вместо 48). Поэтому одно задание живёт ~5 часов
  (10 проверок по границам :00/:30, каждая коммитится ботом `uptime-bot`),
  а в конце само запускает следующее через `gh workflow run`. Cron
  `23 */2 * * *` — только страховка на случай обрыва цепочки. Если задание
  прожило меньше 20 минут (упало), оно себя не перезапускает — ждёт cron.
  Коммиты без `[skip ci]`, иначе Pages не пересобирается.
  Цепочку надо один раз запустить руками: `gh workflow run check.yml`.
- `docs/index.html` — табло, читает `data/status.json`, обновляется само раз
  в 5 минут. Публикуется GitHub Pages из папки `/docs` ветки `main`.
- Репозиторий **публичный** — бесплатные Pages на этом аккаунте работают
  только так. В нём нет ничего, кроме адресов сайтов и истории ответов.

## Правила
- Список сайтов — только в `SITES` внутри `check.py`.
- Пороги (5 КБ, 5 с, 30 с таймаут) описаны в подвале табло; меняешь порог —
  меняй и подвал.
- Данные `docs/data/` правит бот; руками не трогать, при конфликте —
  `git pull --rebase`.
- Проверка идёт из США (GitHub). Это внешний взгляд, не замер из России.
- `check.py` без аргументов СРАЗУ делает проверку и переписывает
  `docs/data/` — локально не запускать (06.11.2026 запустил «--help»,
  пришлось откатывать данные).
